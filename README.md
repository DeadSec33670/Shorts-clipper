# Shorts Clipper

AI-нарезка вертикальных шортсов из длинных видео. На входе — ссылка на YouTube
или видеофайл, на выходе — готовые клипы 9:16 с анимированными субтитрами
и кадром, который следит за говорящим.

Работает как из командной строки, так и через веб-панель с очередью задач,
учётными записями и квотами.

---

## Как это работает

```
Видео → скачивание → распознавание речи → поиск моментов → кадрирование → рендер → клипы
         yt-dlp       faster-whisper        LLM             OpenCV          ffmpeg
```

| Этап | Что происходит |
|---|---|
| **Скачивание** | `yt-dlp` (ссылка) или копирование локального файла |
| **Распознавание** | `faster-whisper` с тайм-кодами по каждому слову |
| **Поиск моментов** | LLM оценивает фрагменты по «виральности» и возвращает лучшие |
| **Кадрирование** | Детекция и трекинг лиц, сглаживание движения камеры (1€-фильтр) |
| **Кто говорит** | Опционально Light-ASD — определяет активного спикера по губам |
| **Субтитры** | Караоке-стиль: слово подсвечивается ровно в момент произнесения |
| **Рендер** | `ffmpeg`, аппаратное кодирование NVENC при наличии видеокарты |

## Быстрый старт

Нужен **Python 3.10+** и **ffmpeg**.

```bash
git clone https://github.com/DeadSec33670/shorts-clipper
cd shorts-clipper
python -m venv venv
venv/bin/pip install -r requirements.txt     # Windows: venv\Scripts\pip.exe
```

Ключ для поиска моментов (бесплатный, без карты — Google AI Studio):

```bash
export GOOGLE_API_KEY=ваш-ключ               # Windows: $env:GOOGLE_API_KEY="..."
```

Нарезка одного видео:

```bash
python main.py "https://www.youtube.com/watch?v=XXXX" --clips 5
```

Готовые клипы появятся в `clips/`, рядом — `manifest.json` с заголовками,
хуками и оценкой виральности каждого клипа.

## Веб-панель

```bash
python web.py        # окно 1: сайт на http://127.0.0.1:5000
python worker.py     # окно 2: обработка видео
```

Нужны **оба** процесса: сайт складывает задачи в очередь, воркер их выполняет.
Благодаря этому несколько человек могут работать одновременно, а перезапуск
сайта не убивает начатую обработку.

При первом запуске в консоли один раз покажутся логин и пароль администратора.

Что умеет панель:

- очередь задач с честным распределением — один пользователь с пачкой видео
  не блокирует остальных;
- живой прогресс по этапам с оценкой оставшегося времени;
- история задач, просмотр и скачивание клипов;
- учётные записи, сроки доступа и квоты (минуты видео в месяц,
  одновременные задачи, максимальная длина видео);
- учёт себестоимости: сколько потрачено на запросы к LLM, в разбивке по этапам;
- журнал действий и письма о готовности.

## Основные параметры

```bash
python main.py ВИДЕО [опции]
```

| Опция | Описание |
|---|---|
| `--clips N` | сколько клипов сделать |
| `--length 30s\|1m\|2m` | целевая длительность |
| `--min-sec` / `--max-sec` | точные границы длительности |
| `--model` | модель распознавания (по умолчанию `large-v3-turbo`) |
| `--whisper-device cpu\|cuda` | где распознавать речь |
| `--language ru` | язык (по умолчанию определяется автоматически) |
| `--llm-provider` | `gemini`, `groq`, `openrouter` или `claude` |
| `--asd` | точное определение говорящего (нужен PyTorch) |
| `--static-fit` | без слежения за лицом, статичный кадр |
| `--no-subs` | без субтитров |
| `--font` | шрифт субтитров |
| `--proxy` | прокси для скачивания |
| `--films A B C` | пакетная обработка нескольких видео |

Полный список: `python main.py --help`

## Настройка через переменные окружения

Ключи LLM (достаточно одного — того провайдера, которым пользуетесь):

```bash
GOOGLE_API_KEY=...        # Gemini, бесплатно
GROQ_API_KEY=...          # Groq, бесплатно
OPENROUTER_API_KEY=...
ANTHROPIC_API_KEY=...     # Claude, платно
```

Остальные настройки — в [`deploy/env.example`](deploy/env.example): сроки
хранения файлов, SMTP для уведомлений, S3, прокси, параметры базы.

**Ключи задаются только через переменные окружения.** В репозитории их нет
и быть не должно.

## Запуск на сервере

Подробная инструкция — в [DEPLOY.md](DEPLOY.md). Коротко:

```bash
cp deploy/env.example .env
nano .env                       # обязательно CLIPPER_SECRET_KEY
docker compose up -d --build
```

Поднимутся четыре службы: сайт, воркер, очистка диска, резервное копирование.
Для доступа к видеокарте из контейнера нужен NVIDIA Container Toolkit.

Есть и установка без Docker — через systemd и nginx, конфиги лежат в
[`deploy/`](deploy/).

Публичный режим (`CLIPPER_PUBLIC=1`) включает защиту для работы в интернете:
запрещает чтение файлов с диска сервера, требует HTTPS для cookie, отключает
отладочные возможности. **Не выкладывайте сервис наружу без него.**

## Проверки

```bash
python run_tests.py
```

| Набор | Что проверяет | Проверок |
|---|---|---|
| `tests_pipeline.py` | разбор ответа LLM, субтитры, тайминги | 54 |
| `tests_security.py` | CSRF, лимиты входа, пути, заголовки | 23 |
| `tests_multiuser.py` | изоляция пользователей, квоты, очередь | 59 |
| `tests_storage.py` | ключи S3, подписанные ссылки, удаление | 22 |
| `tests_ui.py` | все кнопки и адреса интерфейса работают | 62 |

Стоит прогонять перед каждым обновлением на сервере.

Отдельно стоит сказать про `tests_pipeline.py`: ответ языковой модели — самое
хрупкое место всего пайплайна. Он регулярно приходит повреждённым: обрезанным
по лимиту токенов, в markdown-обёртке, с висячими запятыми. Разбор проверяется
на всех известных видах порчи, включая обрыв на середине — из такого обломка
вытаскиваются все целые клипы, и прогон продолжается вместо падения.

## Требования

- Python 3.10+
- ffmpeg (для аппаратного кодирования — собранный с NVENC)
- Видеокарта NVIDIA желательна, но не обязательна: без неё распознавание
  и рендер идут на процессоре, просто медленнее
- PyTorch — только для режима `--asd`, ставится отдельно под вашу версию CUDA

## Известные сложности

**YouTube не отдаёт видео.** Сервис активно противодействует скачиванию.
Помогают: обновление `yt-dlp` (`pip install -U yt-dlp`), прокси
(`CLIPPER_PROXY`), смена клиента (`CLIPPER_YT_CLIENTS=android,ios`). Программа
сама перебирает клиентов при ошибке 403 и повторяет задачу при временных сбоях.

**LLM не работает в вашем регионе.** Gemini отвечает «User location is not
supported» в части стран. Прокси применяется и к запросам к LLM, либо можно
переключиться на Groq — он доступен шире.

**Ошибки CUDA/cuDNN.** Несовместимость версий `ctranslate2` и cuDNN даёт
падение после распознавания. Лечится обновлением (`pip install -U ctranslate2
nvidia-cudnn-cu12`) либо переходом на процессор (`--whisper-device cpu`).
Распознанный текст сохраняется построчно, поэтому при сбое работа не теряется —
повторный запуск продолжит с места обрыва.
